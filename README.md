# craters-sandbox

A collection of examples, demos, and sandboxes built with the [CRATERS](https://github.com/john-swana/craters) game engine. These projects demonstrate various features and capabilities of the engine.

## Examples

### [SAT Collision](https://john-swana.github.io/craters-sandbox/sat/index.html)
A demonstration of the Separating Axis Theorem (SAT) collision detection library integrated into CRATERS. Features interactive shape control and a benchmark mode with QuadTree spatial partitioning.

### [Tilemap Manager](https://john-swana.github.io/craters-sandbox/tilemap-manager/index.html)
A sandbox for testing and demonstrating the TilemapManager component, including loading and rendering tilemaps.

### [Sprite](https://john-swana.github.io/craters-sandbox/sprite/index.html)
Basic sprite rendering and animation examples.

### [Font](https://john-swana.github.io/craters-sandbox/font/index.html)
Demonstration of the FontManager and text rendering capabilities.
